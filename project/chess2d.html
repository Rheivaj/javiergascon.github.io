Chess 2D Mobile

Primary Focus: Mobile UI/UX & WebGL Deployment

WebGL Unity C# Chess Engine Mobile Game 2D Gameplay

Play this beautiful 2D Chess game, designed specifically for mobile devices, directly in your browser. This project showcases standard chess rules, board state evaluations, clean user interface animations, and a seamless mobile WebGL deployment.

The gameplay has been fully optimized to work on touch screens, featuring responsive canvas resizing and light resource consumption.

Tip: Play with touch gestures or mouse drag-and-drop!

Core Features

Gameplay & Chess Rules Engine

C# Game Logic Rules Engine

Implemented core chess mechanics and validation systems including:

  • Move Validation: Accurate logic for all classic pieces (pawns, knights, bishops, rooks, queens, kings).
  • Special Rules: Support for castling, en passant, and pawn promotion.
  • Game Loop: Turn-based system with detection for check, checkmate, and stalemate.

The rules engine is designed to be robust, preventing invalid board configurations.

Mobile UI/UX Design

UI/UX Responsive Canvas Touch Controls

Focused on creating a smooth and pleasant experience for touch devices:

  • Responsive Layout: The game canvas automatically adapts to vertical orientations typical of mobile screens.
  • Touch Inputs: Drag-and-drop mechanics optimized for precise touch screen control.
  • Minimalist Aesthetics: Clean visual design that minimizes distractions and enhances readability of the board.

This ensures the game remains highly playable on all screen sizes.
